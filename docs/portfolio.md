## LinkedIn post (after shipping)

I’ve been building Spendwise 💸 — a personal finance dashboard that started with a simple question: how can I track everyday spending with less manual effort?

Using Next.js, TypeScript, Supabase (PostgreSQL), and Recharts, I built an app that lets users organize transactions, correct merchant categories, set monthly budgets, and explore spending patterns through interactive reports.

One of the most interesting challenges has been exploring iOS Shortcuts as a transaction input source. I built a protected REST ingestion endpoint with amount validation, merchant-based categorization, and duplicate checks. Real-world Apple Wallet automation is still experimental, so I also added manual entry and CSV import as reliable alternatives.

I’ve put together a public demo using fictional transactions, so anyone can try the dashboard without creating an account or accessing private financial data.
